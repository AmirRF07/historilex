## 📖 درباره پروژه
**HistoriLex (تاریخ‌واژه)** یک وب‌اپلیکیشن پیش‌رونده (PWA) مستقل، سبک و بومی‌سازی‌شده است که به‌طور اختصاصی برای پژوهشگران، دانشجویان و علاقه‌مندان به **تاریخ ایران پس از اسلام** و **مطالعات نظری تاریخ‌نگاری** طراحی شده است.

این نرم‌افزار به شما کمک می‌کند اصطلاحات بنیادین و تخصصی متون آکادمیک بین‌المللی (Scientific Jargon) را همراه با تعاریف دقیق، هم‌آیی‌ها (Collocations)، شواهد متنی، تبارشناسی تاریخی و تلفظ صوتی از طریق سیستم علمی مرور تکرار فاصله‌دار فرا بگیرید.

## ✨ امکانات کلیدی

- **مرور هوشمند روزانه (FSRS Flashcards)**: تنظیم فواصل مرور کارت‌ها بر اساس درجه سختی (دوباره، دشوار، خوب، آسان) و محاسبه زنجیره استمرار روزانه (Streak).
- **اطلس و جستجوی چندبعدی**: جستجوی سریع در واژگان انگلیسی، معانی فارسی، ریشه‌ها و فیلتر بر اساس موضوع یا هر یک از ۱۱ کتاب مرجع.
- **تلفظ صوتی آفلاین**: تلفظ کلمات با استفاده از Web Speech API مرورگر با لهجه آکادمیک (UK / US) بدون نیاز به اینترنت یا کلیدهای API تجاری.
- **آزمون و تمرین ۴ گزینه‌ای**: سوالات خودکار دوطرفه (انگلیسی به فارسی و تحلیل مفهومی به اصطلاح انگلیسی).
- **کتابخانه و راهنمای دانلود مراجع**: دسترسی به مشخصات کتاب‌ها و کپی با یک کلیکِ کوئری‌های دقیق دانلود PDF.
- **قابلیت افزودن اصطلاحات شخصی**: امکان وارد کردن واژگان جدید از مقالات و رساله‌های دلخواه با ذخیره‌سازی نامحدود در حافظه محلی.
- **پشتیبان‌گیری و بازیابی**: خروجی JSON از تمامی کارت‌های مطالعه‌شده و اصطلاحات جدید بدون وابستگی به سرور.
- **PWA (نصب روی موبایل مانند اپلیکیشن بومی)**: کاملاً واکنش‌گرا با منوی ناوبری پایین گوشی، قابلیت Add to Home Screen در اندروید و iOS.

## 📱 دریافت فایل نصبی مستقیم (APK برای اندروید)

این پروژه به دو روش سریع فایل نصبی APK را به شما ارائه می‌دهد:

### روش ۱: بیلد کاملاً خودکار در گیت‌هاب (پیشنهادی - بدون نیاز به نصب هیچ برنامه‌ای)
فایل گردش‌کار `.github/workflows/build-apk.yml` در پروژه قرار داده شده است. به محض اینکه کدها را در گیت‌هاب پوش کنید:
1. در صفحه مخزن گیت‌هاب خود به تب **Actions** بروید.
2. گردش‌کار **Build Android APK** به صورت خودکار اجرا شده و توسط سرورهای ابری گیت‌هاب (همراه با Android SDK و Gradle) خروجی نهایی تولید می‌شود.
3. پس از اتمام (حدود ۲ دقیقه)، روی اجرا کلیک کرده و در بخش **Artifacts**، فایل **HistoriLex-APK** را مستقیماً دانلود کنید و روی گوشی نصب نمایید!

### روش ۲: ساخت فوری آنلاین با PWABuilder (رسمی مایکروسافت در ۳۰ ثانیه)
1. وارد سایت [PWABuilder.com](https://www.pwabuilder.com/) شوید.
2. آدرس گیت‌هاب پیجز برنامه خود را وارد کنید (`https://USERNAME.github.io/historilex/`).
3. روی دکمه **Package for Android** کلیک کنید تا فایل APK را فوراً تولید و دانلود کنید.

## 🚀 راهنمای راه‌اندازی و انتشار در گیت‌هاب (GitHub Pages)

### ۱. تست محلی روی سیستم:
```bash
npm install
npm run dev
```

### ۲. استقرار رایگان روی گیت‌هاب (گام به گام):
1. در حساب کاربری [GitHub](https://github.com) خود یک مخزن جدید (New Repository) مثلاً با نام `historilex` بسازید (Public باشد).
2. داخل پوشه پروژه دستورات زیر را در ترمینال اجرا کنید:
```bash
git init
git add .
git commit -m "Initial commit: HistoriLex Academic Jargon Atlas"
git branch -M main
git remote add origin https://github.com/USERNAME/historilex.git
git push -u origin main
```
3. وارد تنظیمات مخزن در گیت‌هاب شوید:
   - به تب **Settings** بروید.
   - از منوی سمت چپ روی **Pages** کلیک کنید.
   - در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** تنظیم کنید.
4. با اولین پوش، اکشن از پیش تنظیم‌شده (`.github/workflows/deploy.yml`) به صورت خودکار پروژه را بیلد کرده و اپلیکیشن شما روی آدرس زیر به صورت زنده در دسترس قرار می‌گیرد:
   ```
   https://USERNAME.github.io/historilex/
   ```
5. اکنون کافی است در گوشی خود این آدرس را با مرورگر (Chrome یا Safari) باز کنید و دکمه **Add to Home screen** یا **نصب برنامه** را بزنید تا برنامه مثل یک اپلیکیشن بومی در کنار برنامه‌های گوشی شما قرار گیرد!
